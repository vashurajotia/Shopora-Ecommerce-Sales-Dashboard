
# 🛍️ Shopora – E-commerce Sales Dashboard

A beginner-friendly e-commerce sales analysis dashboard built using Microsoft Power BI.

## 📊 Project Overview

Shopora is my first Power BI dashboard project, created to explore e-commerce sales data and visualize important business metrics.

The dashboard provides insights into sales performance, product categories, and city-wise revenue through interactive visualizations.

## ✨ Dashboard Highlights

- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Order Value
- Revenue by City
- Revenue by Category
- Price vs. Revenue Analysis
- Top Revenue Product

## 🛠️ Tools & Technologies

- Data Visualization
- Business Intelligence
- Data Analysis
